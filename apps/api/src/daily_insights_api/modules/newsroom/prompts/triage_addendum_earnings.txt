## 同一次財報的事件歸屬

本段補充上方「事件歸屬（event）」的規則，其餘規則不變：
- 同一家公司同一次財報與法說會（含財報電話會議）公布的不同數字、財測與主管談話，屬於同一核心事件。例如營收、獲利、毛利率、資本支出、下一季或全年財測，以及執行長或財務長在法說會上的說明，都是同一事件的不同角度。
- candidate_events 中已有同一家公司同一次財報或法說會的事件時，必須輸出 {"match": "<該事件的 id>"}；不得因為本文報導的是另一個數字、另一項財測或另一位主管的談話而開新事件。
- 下列情況仍是不同事件，應依上方規則判斷：不同公司的財報，即使同一天公布；同一家公司不同期的財報，或月營收等其他數據；財報公布前的預告與預期，與公布後的結果；同一家公司與這次財報無關的消息，例如新產品、訴訟、人事或併購；以及在財報或法說會上一併宣布的獨立決策，例如合併、合資、新建廠房或量產計畫。
- 一篇文章同時報導多家公司的財報時，依文章主要報導的那一家公司判斷；分不出主次時，不得歸入任一家公司的財報事件。
