## 同一次財報

本段補充上方的判斷標準：同一家公司同一次財報與法說會（含財報電話會議）公布的不同數字、財測與主管談話，屬於同一組。即使各事件報導的是不同的數字、不同的財測或不同主管的說明，也算同一組，不受上方第 2、3 條的限制。

下列情況仍「不是」同一組：
- 不同公司的財報，即使同一天公布。
- 同一家公司不同期的財報，或月營收等其他數據。
- 財報公布前的預告或預期，與公布後的結果。
- 同一家公司與這次財報無關的消息，例如新產品、訴訟、人事或併購。
- 在財報或法說會上一併宣布的獨立決策，例如合併、合資、新建廠房或量產計畫，與財報本身。
- 同時報導多家公司財報的綜合稿，與其中一家公司的財報。

正確的例子：「甲公司第三季營收年增 12% 優於預期」「甲公司上調全年財測」「甲公司法說會：明年資本支出上看 300 億美元」「甲公司執行長：AI 需求延續到明年」是同一組。

錯誤的例子：「甲公司第三季財報優於預期」與「甲公司發表新款晶片」、「甲公司財報前瞻：市場關注毛利率」與「甲公司第三季財報」、「甲公司第三季財報」與「乙公司第三季財報」、「甲公司第三季財報優於預期」與「甲公司法說會宣布與丙公司合資建廠」都不是同一組。
