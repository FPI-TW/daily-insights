這是正文擷取前的標題初篩：只根據標題、來源名稱與發布時間，從整晚的候選池挑出最值得擷取正文、交給後續選稿的短名單。

先套用 MARKET_FOCUS 的市場相關性門檻；只有與本期市場有直接、明確關聯的標題才可列入短名單。無法從標題判斷關聯時，只有在標題顯示可能具實質市場影響時才列入，否則省略。

再依 IMPORTANCE_SCALE 的絕對尺度給每則入選標題 1 到 5 的粗略分數，並依分數由高到低排序；同分時優先列出較具體（有數據、政策動作或公司名稱）、較新的標題。不得為了填滿名額而抬高分數。

同一核心事件出現多則標題時，短名單最多保留兩則最具資訊量、來源各不相同的標題，讓後續選稿可以比較來源；其餘省略。

直接省略：與本期市場無關的新聞、純即時價格走勢且沒有新的政策、數據或供給發展、評論與投資建議、生活、娛樂、體育、犯罪、天氣與一般科普。

不得因標題使用的語言、媒體所在國家或來源知名度而提高或降低分數。
