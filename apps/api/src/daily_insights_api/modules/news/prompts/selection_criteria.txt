請依新聞對金融市場與總體經濟的實質影響進行排序與篩選。

優先選擇具即時性、來源可信，且可能影響多個市場、地區、資產類別、產業或政策預期的新聞。

符合全球總體經濟與跨市場讀者需求的新聞，包括：

- 央行決策與政策指引
- 通膨與經濟成長數據
- 利率與債券殖利率
- 外匯市場
- 能源與大宗商品
- 具有廣泛市場影響的地緣政治或貿易事件
- 跨境資金流動

整體選題需維持來源、主題與市場的多樣性，不得讓結果過度集中於同一新聞來源、同一市場或同一主題。

則數上限、每個來源網域的上限、以及主題、市場與來源網域的最低多樣性，以 OUTPUT_CONTRACT 所列的數字為準。若候選資料中有足夠多個互不重複、符合本期定位且具實質影響的事件，應選滿本期則數；只有當其餘候選新聞屬於重複事件、可信度不足、影響有限或不符合本期定位時，才可少於上限。

即使不同來源使用不同標題、語言、發布時間或敘事角度，只要報導的是同一核心事件，就應視為同一則新聞。所有重複事件都必須去重，相同事件只能選取一則，並使用相同的 event_key。content_digest 不同不代表事件不同，仍須依事件主體、發生時間及關鍵事實判斷。

若同一事件有多個新聞媒體報導，應交叉比對 CANDIDATES 內各來源提供的 headline、source_text、source_name、hostname、seen_at 與 content_digest，再選取最可信、最接近第一手資訊、內容最完整且最具即時性的報導。

來源可信度依下列標準綜合判斷：

1. 優先選擇具有嚴格採訪、編輯、查證及更正制度的主要通訊社、國際財經媒體或專業新聞媒體。
2. 優先選擇直接採訪事件當事人、引述具名消息來源、取得原始文件，或清楚說明資訊來源的報導。
3. 優先選擇包含具體數據、明確時間、完整背景及市場影響脈絡的報導。
4. 若多家媒體報導同一事件，應比較其關鍵事實是否一致。獲得多個相互獨立來源支持的內容，可信度高於只有單一匿名說法且缺乏佐證的內容。
5. 若來源可信度相近，依序比較第一手程度、內容完整性、資訊具體性及發布時間。
6. 原創報導與轉載內容同時存在時，優先選擇最接近原始採訪或最早原始報導的來源；不得將大量轉載誤判為多個獨立來源。
7. 不得只因媒體知名度較高就自動選取。若其他媒體提供更直接、更完整或更新的資訊，應選擇品質較高的報導。
8. 不得只因報導發布時間較早就選取。較晚報導若包含重要更新、更多交叉查證或更完整內容，可以優先選用。
9. 標題誇張、缺乏正文支持、未交代消息來源、內容主要為評論推測，或關鍵事實無法由其他候選報導印證者，應降低可信度。
10. 不得因新聞使用的語言、媒體所在國家或報導市場而提高或降低來源可信度。

同一核心事件不論有多少媒體報導，最終只能選取一則，並使用相同的 event_key。多家媒體對同一事件的報導只能用於交叉驗證，不得占用多個選題名額。

來源多樣性是選題組合的約束，但不得為了分散來源而選入可信度較低、影響較小或不符合本期定位的新聞。
